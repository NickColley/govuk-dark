# GOV.UK Dark mode theme

Experimental GOV.UK Dark mode theme User Style.

For testing purposes, do not ship in production.

# How to install

1. Install Stylus (https://github.com/openstyles/stylus#releases) (or any extension that supports CSS User Styles)
2. Install the [GOV.UK Dark mode theme](https://raw.githubusercontent.com/NickColley/govuk-dark/master/govuk-dark.user.css)
